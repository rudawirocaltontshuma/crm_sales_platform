# Dimension CRM

**Dimension CRM** is an enterprise Customer Relationship & Sales Management Platform frontend, built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

It is a frontend-only build: every screen renders from a deterministic, seeded mock dataset generated in TypeScript. There is no backend, no database, no authentication, no external APIs, and no persistence — nothing you do in the UI is saved between reloads. It exists to be a clean, complete reference implementation of a CRM's UI and interaction patterns that other developers can read, run, and build on.

## Modules

- **Dashboard** — KPIs, revenue/pipeline trend charts, sales-by-rep and sales-by-region breakdowns, recent activity, and upcoming tasks
- **Leads** — directory with stage tracking (New → Contacted → Qualified → Proposal → Converted/Lost) and detail pages
- **Contacts** — contact directory and profiles
- **Companies** — company directory with tabbed detail pages (Overview, Contacts, Deals, Activities, Tasks, Timeline)
- **Deals** — deal management with stage, probability, and expected close date
- **Pipeline** — drag-and-drop Kanban board across seven deal stages
- **Activities** — a unified timeline of calls, meetings, emails, notes, and tasks
- **Tasks** — task tracking with status and priority
- **Calendar** — month/week/day/agenda views of scheduled events
- **Sales Teams** — representative and team performance
- **Products** — product catalog with pricing and sales figures
- **Quotes** — a quote builder with line items, discounts, tax, and status tracking
- **Customers** — customer-account overview (revenue, orders, retention, growth)
- **Support** — ticket queue with priority, agent, and status
- **Reports** — sales, lead, pipeline, revenue, representative, customer, and activity reports
- **Analytics** — chart-driven sales, lead, pipeline, customer, and representative analytics
- **Settings** — account and workspace preference screens

All records — 250+ leads, 300+ contacts, 150+ companies, 200+ deals, 400+ activities, 200+ tasks, 100+ products, 100+ tickets, and more — are generated by a seeded random-data pipeline in `src/data/dimension/`, so the data is realistic and stable across builds without any external service.

## Tech Stack

- **Framework**: Next.js 16 (App Router), TypeScript, Tailwind CSS v4
- **UI Components**: shadcn/ui
- **Tables & Data Handling**: TanStack Table
- **Charts**: Recharts
- **Drag & Drop**: dnd-kit (pipeline Kanban)
- **Calendar**: FullCalendar
- **Forms & State**: React Hook Form, Zustand
- **Tooling**: Biome, Husky

## Getting Started

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/rudawirocaltontshuma/crm_sales_platform.git
   ```

2. **Navigate into the project**
   ```bash
   cd crm_sales_platform
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

The app runs at [http://localhost:3000](http://localhost:3000) and redirects to `/dashboard/dimension`, the CRM overview.

### Build

```bash
npm run build
npm run start
```

### Formatting and Linting

```bash
npm run lint      # Biome lint
npm run check     # Biome check (lint + format)
npm run check:fix # Biome check with autofix
```

## Project Structure

This project follows a colocation-based architecture: each screen keeps its own page, components, and mock-data usage inside its own route folder. Shared UI, hooks, and configuration live at the top level.

```
src
├── app
│   └── (main)
│       └── dashboard
│           ├── dimension        # Dimension CRM module
│           │   ├── leads
│           │   ├── contacts
│           │   ├── companies
│           │   ├── deals
│           │   ├── pipeline
│           │   ├── activities
│           │   ├── tasks
│           │   ├── calendar
│           │   ├── sales-teams
│           │   ├── products
│           │   ├── quotes
│           │   ├── customers
│           │   ├── support
│           │   ├── reports
│           │   ├── analytics
│           │   ├── settings
│           │   └── _components  # shared CRM UI (data table, charts, detail views)
│           └── _components      # shared dashboard shell (sidebar, header)
├── data
│   └── dimension                # seeded mock-data generators and derived aggregates
├── components/ui                # shadcn/ui primitives
├── navigation/sidebar            # sidebar navigation config
├── hooks
├── lib
└── styles
```
